# Lunar Outpost Watch

Extend/create "Solar Watch" in React + TypeScript + Tailwind using @react-three/fiber and @react-three/drei
(low-poly, procedural only). Use the GAME BIBLE. Build: a 3D solar-system hub with clickable planets, a Moon
surface scene and a Mars surface scene with terrain, a day/night cycle, modular building placement with ghost preview,
rover driving, and a space-weather alert system with a Sun flare effect. Put the HUD in regular React/Tailwind overlays.
Keep game rules in a separate TypeScript simulation module (no logic in components). Keep the code clean and
mobile-friendly with a quality toggle. Start with the Moon scene, then I will request Mars and Earth.
